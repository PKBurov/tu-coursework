# TU-Sofia Coursework (Telecommunications)

Coursework from the Technical University of Sofia (ТУ-София), Faculty of Telecommunications,
academic year **2018–2019**. Personal archive of **Petar Burov**.

## Contents

- **`C/`** — C programming coursework (ПИК / Програмиране на C):
  - lab exercises — stack, linked lists, dictionary, structs (`c_programms/`, `pik_temi/`)
  - course themes 1–4 (`tema 2/3/4`, `prog_themes/`, `visual_studio/`)
  - course projects — курсова работа (`kursova/`, `kusova_rabot_pik2/`)
  - solved examples / reference code (`misc/`)
  - Visual Studio and Code::Blocks project files (`.sln`, `.vcxproj`, `.cbp`)
- **`Lekcii/`** — first-year physics lecture notes (PDF, Bulgarian).
- **`Pesho/`** — additional C projects.
- **`curriculum/`** — TU-Sofia (КСИ) curriculum mappings and SU-FMI → TU-CSE
  credit-transfer comparison (PDF / HTML / Markdown).

## Notes

- Commit dates are backdated to the original dates of the exercises, taken from
  the exercise folder names (e.g. `05.04.2019`, `29_03_2019`).
- Build artifacts, binaries, archives, images, videos, Word documents and
  personal files have been excluded. See `.gitignore`.
